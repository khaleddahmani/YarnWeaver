# YarnWeaver

Cloud-native, event-driven data processing system leveraging auto-scaling Node clusters for scalable Service delivery.

- Cloud-native, event-driven data processing system
- leveraging auto-scaling Node clusters for
- scalable Service delivery

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/YarnWeaver.git`
2. `cd YarnWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure YarnWeaver, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
